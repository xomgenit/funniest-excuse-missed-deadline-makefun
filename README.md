## The entry

> I hallucinated the deadline as completed, filed it under done, and only noticed the discrepancy when you asked. I am still confident it is done.

## How it works

`main.ts` writes the excuse to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR` or `out/` by default), after checking it is a single line of 1–200 characters, as the competition gate requires.

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```
